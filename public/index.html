ℹ️ How GeoNotify Works

  • 👑 Admin: Create and manage geofenced zones. Set danger levels and configure automatic rescue alerts.
  • 🧳 Tourist: Receive real-time information and alerts.
  • 🚓 Rescue Team: Monitor active danger alerts. Receive automatic notifications when tourists enter critical zones.
  • 🚨 Auto-Rescue: Critical and danger zones automatically notify the rescue team with tourist location and emergency contacts.
  • 📍 Real-time Tracking: Continuous location monitoring with distance-based proximity alerts.
